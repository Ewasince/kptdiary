# КПТ-дневник

Личный дневник КПТ по «Протоколу дисфункциональных мыслей»: ситуация, эмоции (по колесу
Плутчика) с интенсивностью, автоматические мысли и рациональный ответ. Работает в браузере
как PWA, ставится на телефон и работает офлайн. Все данные хранятся только на устройстве
(`localStorage`), сервера нет. Подробное описание — в
[спецификации](docs/superpowers/specs/2026-10-20-kptdiary-design.md).

## Запуск локально

```sh
npm install
npm run dev     # дев-сервер, адрес напечатается в консоли
npm run check   # типы, линтер и тесты
npm run build   # сборка в dist/
```

## Деплой

Сборка публикуется на GitHub Pages workflow-ом `.github/workflows/deploy.yml` при каждом пуше
в `master` (или вручную через «Run workflow»). Один раз нужно включить Pages: Settings → Pages →
Source «GitHub Actions».

По умолчанию приложение собирается для пути `/kptdiary/`. Для другого хостинга базовый путь
задаётся переменной `VITE_BASE`, например для корня домена:

```sh
VITE_BASE=/ npm run build
```

## Установка на Android

Откройте страницу в Chrome, затем меню (⋮) → «Добавить на главный экран». После первой загрузки
приложение работает без интернета. Когда выходит новая версия, внизу появляется плашка
«Доступно обновление» с кнопкой «Обновить».

## Бэкап и перенос между телефоном и компьютером

Данные живут в браузере конкретного устройства, поэтому переносятся файлом:

1. На одном устройстве: «Экспорт» → «Бэкап и перенос» → «Скачать JSON».
2. Отправьте файл себе (почта, мессенджер, облако).
3. На другом устройстве: «Импортировать», выберите файл, проверьте сводку и нажмите «Применить».

Импорт объединяет данные: добавляет новые записи и обновляет изменённые, но никогда ничего
не удаляет. Регулярный бэкап — единственная защита от потери данных при очистке браузера.

## Отчёт для терапевта

«Экспорт» → «Отчёт для терапевта»: выберите период (день, неделя, месяц, с последней выгрузки,
всё время или свои даты), затем «Открыть отчёт», «Сохранить HTML» или «Сохранить PDF».
PDF сохраняется через печать браузера («Сохранить как PDF» в диалоге печати).
