# Макеты

Двенадцать артбордов утверждённого дизайна. Для каждого: `NN-name.html` (самостоятельная страница,
открывается в любом браузере, зависимостей нет) и `NN-name.png` (рендер того же артборда в Chromium
при размере артборда). Описание каждого в разделе 10 файла `../spec.md`, размеры в `index.json`.

Исходно макеты были нарисованы на интерактивном дизайн-холсте; здесь они сконвертированы в
статический HTML: компонент «уровень» вписан в разметку с примерными значениями, интерактив убран.
Шрифт: Inter, если установлен, иначе системный без засечек.
